\section{Setup}
\begin{frame}{Setup}
\begin{itemize}
    \item Expand the provided PythonCourse.zip file to a location of your choice.
    \item Cmd prompt at the PythonCourse folder (right click on folder, select "Open with cmd"). For macOS, open terminal and \texttt{cd} to the PythonCourse folder.
    \item type: "\texttt{python --version <Enter>}" (or try \texttt{python3 --version <Enter>} on macOS), you should see the Python version you installed. If you don't, ask AI until you do (reinstall python for example).
    \item type: "\texttt{python setup\_env.py <Enter>}"
    \item At the end of the script, it says "Next steps: Activate the environment" and tells you what to type. Type that.
    \item type: "\texttt{jupyter notebook <Enter>}". This should open a browser window with the Jupyter interface. This is the basic setup, we can work from here, but I am showing you a better way too. 
\end{itemize}
\end{frame}

\begin{frame}{Better Way}
\begin{itemize}
    \item Open VSCode
    \item Open folder: \textbf{File $\rightarrow$ Open Folder...} and select the unzipped PythonCourse folder.
    \item On the left side you find the file explorer.  Click \texttt{python\_intro\_stats\_notebook.ipynb}
    \item If VS Code asks to install recommended extensions, click \textbf{Yes}.
    \item If VS Code asks what kernel to use, click the one called "venv".
\end{itemize}
\end{frame}
